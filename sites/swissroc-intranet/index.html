Service IT — Swissroc

Vous venez de vous faire piéger.

Cette page n'était pas le vrai portail Swissroc. C'était un test de sensibilisation au phishing mené par le Service IT. Dans un vrai cas, vos accès seraient désormais entre les mains d'un attaquant.

Vos identifiants n'ont PAS été collectés. Rien de ce que vous avez saisi (e-mail, mot de passe) n'a été enregistré, transmis ni stocké. Vous n'avez aucune action de sécurité à entreprendre sur votre compte.

Que s'est-il passé ?

Vous avez reçu un message contenant un lien. Ce lien menait à une page imitant la connexion Microsoft, puis à une copie du Swissroc Hub. En saisissant votre e-mail et votre mot de passe, vous avez fait exactement ce qu'un attaquant attend. Ici, rien n'a été capté ; dans une véritable attaque, vos accès seraient compromis en quelques secondes. Ce test n'a qu'un but : ancrer un réflexe — vérifier avant de saisir.

Les indices que vous auriez pu repérer

Dans la barre d'adresse (le signe le plus fiable)

  • swisssroc.com — trois « s » au lieu de deux. Un caractère glissé dans le nom de domaine : c'est du typosquatting, la technique reine du phishing.
  • La « connexion Microsoft » ne se faisait pas sur login.microsoftonline.com. Une authentification Microsoft 365 légitime passe toujours par ce domaine — jamais un autre.
  • Le faux intranet s'affichait sur sharepoint.swisssroc.com. Le vrai SharePoint de Swissroc est sur swissrocswiss.sharepoint.com : un espace Microsoft est toujours en *.sharepoint.com, jamais sur un domaine maison.

Sur la page elle-même

  • La petite clé « Options de connexion » n'était pas le symbole exact de Microsoft : un dessin approximatif.
  • Le fond d'écran de la page de connexion ne correspondait pas à l'arrière-plan réel de Microsoft (un dégradé générique au lieu de l'illustration habituelle).
  • Les liens de bas de page (« Conditions d'utilisation », « Confidentialité et cookies ») ne menaient nulle part.
  • Les liens « Votre compte n'est pas accessible ? » et « J'ai oublié mon mot de passe » étaient inactifs.
  • Le parcours était trop lisse : aucune validation MFA, et aucune charte Swissroc affichée après la saisie de l'e-mail, alors que le vrai portail reprend la marque de l'entreprise.

Dans le message reçu

  • Une demande de reconnexion inattendue, souvent teintée d'urgence (« votre session a expiré », « action requise »).

Les bons réflexes

  • Vérifier l'URL dans la barre d'adresse avant de saisir le moindre identifiant.
  • Retenir qu'une connexion Microsoft 365 se fait toujours sur login.microsoftonline.com.
  • Survoler un lien pour lire sa vraie destination avant de cliquer.
  • Se méfier de toute demande de reconnexion inattendue ou urgente.
  • Dans le doute : ne rien saisir et signaler au Service IT.
